# Mise à jour de la charte Cartronic

Cette version aligne le site Angular sur la direction visuelle de `cartronic-vitrine.html`.

Principales modifications :

- palette centrale : bleu `#0B6FBB`, bleu accent `#1E9BF0`, bleu nuit `#0D1B26`, fond clair `#EAF5FE` ;
- typographie unique : Archivo pour les textes et les titres ;
- titres plus francs, cartes à 20 px de rayon et boutons en forme de capsule ;
- en-tête bleu, navigation blanche et pied de page bleu nuit ;
- page d’accueil harmonisée avec le hero bleu et les deux offres bleu nuit / bleu clair ;
- couleurs dispersées remplacées par des jetons CSS communs ;
- nouveaux titres SEO et Open Graph sans tiret long ;
- nouveau positionnement : « Cartronic | La plateforme numérique des services automobiles » ;
- URL de partage définie sur `https://www.cartronic-system.com/`.
